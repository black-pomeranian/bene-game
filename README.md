# BENE Dream Football

サッカー古着を中心とするアパレル店舗にて設営したPKゲームです。
メンバー二人で共同開発し、自身はゲームロジック部分のコーディングを担当しました。（bene-game/Assets/02_dev-Game/Scripts/以下のすべて）

このゲームではプレイヤーはキッカーとキーパーを交互に交代し、
キッカーはマウスドラッグの速度、方向でシュートコースを決定します。
キーパーはマウスドラッグをトリガーにドラッグ方向へ飛び込みます。

全体としてPS1風のシェーダー、デザインで
ゲームキャラクターは古着店舗のオリジナルウェアを着用しており、
販促的な役割を果たす、子供たちも楽しめるゲームとなりました。

## 実行方法
以下リンクからプレイ可能です。

[BENE Dream Football](https://black-pomeranian.com/Project/DreamFootball/game)

または、以下の方法でUnityプロジェクトから実行可能です。
1. Unity Hubで本プロジェクトフォルダを開く  
2. `Assets/01_Main/Scenes/Main.unity`を起動  
3. Unityエディタ上部の ▶ ボタンで実行可能です

※初回起動時は依存ライブラリの再インポートが発生する可能性があります。
